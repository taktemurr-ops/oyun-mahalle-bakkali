# Mahalle Bakkalı · Corner Shop

Rafları doldur, kasada hızlı ol, dükkânını büyüt.

Müşteriler listelerindeki ürünleri raftan alır. Boşalan rafa dokunup doldur (toptan fiyatı ödenir), sıradakileri kasada öde. Gün sonunda kâr hedefini tut.

100.000 bölüm; her bölüm tohumdan üretilir ve yapay oyuncuyla doğrulanır. 33 dil. Boşta ve Simülasyon merkez uygulamasının oyunu; ortak motor: [simulasyon-motoru](https://github.com/taktemurr-ops/simulasyon-motoru).
